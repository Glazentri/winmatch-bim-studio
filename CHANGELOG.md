# Changelog

## 0.1.0 — developer preview (2026-11-26)

- Shared schedule engine, model review, automatic missing marks and stable-ID revisions.
- Revit ribbon source for model scans, locate, tag placement, IFC export, mark patches and RFA libraries.
- Archicad Python Palette companion with a property mapping wizard.
- IFC reader via IfcOpenShell.
- Manufacturer catalogue matching, configurable CSV profiles and branded schedule sheets.
- Separate opening/actual/model dimensions, subsills and measured quantities, pricing.
- Curtain wall module workspace and site solar compass.
- Databuild training carrier XML and Bluebeam markup-authoring kit.
- Versioned interchange schemas, automated core/contract/UI initialiser tests and browser CI workflow.

Native host verification and actual rendered UI test are release gates, not claimed successful.
